统计学习导论：Python 应用 · 中文译本

译者序

作为一名生物信息学方向的博士研究生，随着学习与研究的深入，译者逐渐认识到，生物信息学并不止于运行几段 Linux 命令、调用几个 R 语言包，或绘制一组用于论文展示的精美图表。更重要的是，理解数据背后的生物学问题，选择恰当的分析方法，并对结果作出有依据的解释。

译者曾听一位老师说：“生信即工具。”对此，译者深表认同。生物信息学帮助生物学家探索生命现象，为医学研究提供分析手段，也帮助研究者从复杂的组学数据中提炼信息。人类通过创造和使用工具，不断拓展认识与改造世界的能力；对于科研工作者而言，工具的价值，同样在于帮助我们提出问题、检验证据，并加深对研究对象的理解。

如今，生物信息学领域已经积累了丰富的工具与相对成熟的分析流程。从转录组分析中的“比对 → 定量 → 差异分析”，到蛋白质组学中的“谱图解析 → 搜库 → 定量 → 差异分析”，再到以 Seurat、CellChat 和 Monocle 等为代表的单细胞分析工具，它们为研究者开展工作提供了便利。然而，熟悉操作流程只是起点。要让分析结果可靠、解释合理，还需要理解方法背后的原理、假设与适用条件。

在译者看来，用好这些工具所需要的知识，可以用一个简洁的表达来概括：

\[ \text{生物学} + \text{统计学} + \text{计算机科学} \]

生物学帮助我们提出有意义的问题，统计学帮助我们认识数据中的变异与不确定性，计算机科学则为处理复杂数据提供方法与实现途径。对于许多具有生物学背景的学习者而言，统计学与计算机科学的入门并不轻松，但它们也是理解和运用生物信息学方法不可或缺的基础。

正是出于学习与分享的初衷，译者尝试翻译 Gareth James 等人合著的 An Introduction to Statistical Learning: with Applications in Python（ISLP）。希望这份译文能够帮助中文读者跨越语言障碍，理解常用统计学习方法的基本思想，并将其运用于自己的研究与实践。译者亦在学习之中，译文难免存在疏漏与理解不周之处，诚挚欢迎读者通过本仓库的 Issues 提出意见，共同完善这份译文。
